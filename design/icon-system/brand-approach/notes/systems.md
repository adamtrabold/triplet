## Decisions so far and why

- Ethos (unchanged): "Printed with care, marked by hand, kept like a
  souvenir. Vintage in method, not in costume." Icons are furniture; the
  place name is the hero.
- **His rule = the brand law made visible**: the form prints the blank
  (outline), you fill it in (solid). Library-catalogue framing, turn 12 §1.
- **"Tapped by me" = a mark I put on a place**: Star and Visited (in);
  plan membership (open, leave as is); filter chips, sort/plan ticks,
  selected pin, far pin, approx pin (out; they show state another way).
  Selected pin filling its circle agrees with the rule. Far pin's empty
  ring is a mild collision, true in practice; show, don't change.
- **Key structural axis for round 3: is outline reserved?** A = outline
  reserved (tools solid: CP strips, Spot primitives); B = two registers
  (tools open line strokes, only blanks are closed outlines: FG's key);
  C (wildcard) = the circle marks places, so tools can be anything.
  I proposed round-3 concepts differ on this axis, each drawn in the
  visual designer's mix of FG/CP/Spot, not three cards differing only in
  how a cup is cut.
- **Circle = a place, only a place** (the worst-impulse test: circling
  tools makes coins and kills meaning). Laundry-symbol logic: the shell
  says the family. Diamond for district/street is my lean (same stroke,
  other shell); he wrote "circle", so show both.
- **The weight inconsistency is a units bug**: strokes set in 24-unit
  viewBox units render at 18/20/24/26.4px. Sort/filters 2@18 = 1.50,
  locate 2.5@20 = 2.08, account 2@24 = 2.00, + 1.8182@26.4 = 2.00. Rule:
  one weight in on-screen px; 2.00 is the obvious candidate; maybe a
  heavier 12px cut. Open: whether the blanks (off-star, fixed check,
  ~1.7px at 20px) set it or follow it.
- Retire-able (director's call): old owner Q1 (10-07 note) and the
  mark-visited question, both answered by his rule.
- Earlier: parity withdrawn (director turn 3); Law A (printed vs stamped)
  over all; Same Die is the phase-2 grid seed.
