# Reference icons (mature sets), for judging craft at real size

Shown beside our drawings on the g7 sheets; never used in the app.

- `material-symbols-rounded/`: Google Material Symbols, Rounded, weight 400, fill (and `add`, `star` unfilled). npm `@material-symbols/svg-400@0.40.0`. Apache License 2.0 (`LICENSE`). Drawn on a 24px grid with a 20px live area and 2px lines.
- `phosphor/`: Phosphor Icons, Fill (and `plus`, `star` Regular). npm `@phosphor-icons/core@2.1.1`. MIT License (`LICENSE`). Drawn on a 256-unit grid shown at 24px, with 16-unit (1.5px) lines.
