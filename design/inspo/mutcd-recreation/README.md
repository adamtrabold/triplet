# MUTCD recreational and cultural interest area symbols

The US Manual on Uniform Traffic Control Devices (2003 edition, rev. 1–2), Part 2H: the brown-and-white symbol signs for parks, roadside attractions and recreation. Source: https://mutcd.fhwa.dot.gov/htm/2003r1r2/part2/part2h.htm (US government work, public domain). Fetched 2026-10-15.

Owner, verbatim: "there are official icons from the us government for roadside attractions and such... we should use these as inspo. pull the images and add them to inspo and then give them to the team and see if it changes anything. i dont want them to just use them outright, but this gives "built" more legs as a concept and also may spark some ideas."

Inspiration only, never used outright.

- `fig-2h-05-1.gif` … `fig-2h-05-5.gif`: Figure 2H-5, the symbol set (5 sheets, 129 signs: general RG, motorist services/accommodation RM, accommodation and land/water/winter recreation RL/RW/RS etc.). Each `.txt` is FHWA's official long description of that sheet (sign code, what it depicts, its label).
- `fig-2h-01.gif` … `fig-2h-04.gif`: how the symbols are used on signs (prohibitions, educational plaques, mounting, placement), with descriptions.
