# Inspiration images

Reference images shared during design work, saved here since they came in as
chat uploads and don't otherwise persist anywhere durable.

## `project/`

Overarching visual direction for the app: vintage travel labels (hotel
luggage labels, matchbook collections) and vintage national/state park
posters and trail ephemera. This is the aesthetic language the app's design
tokens (paper/ink/figure-deep colors, ledger-row layout, stamp/label motifs)
draw from.

## `visited-badge/`

Reference specifically for the sidebar "VISITED" stamp badge (see
`../visited-badge/NOTES.md`): passport arrival/departure stamps — ticket-cut
outlines, dotted/dashed borders, bold condensed stamp typography. The
annotated Tokyo stamp crop is the one most directly cited while iterating on
the badge shape.
