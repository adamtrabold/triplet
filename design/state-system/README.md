# State system

One rule per meaning, existing tokens only. The checklist below and every still are GENERATED by `matrix.js` from one table; the run asserts computed styles against the named rule and fails if any cell disagrees. To review: open `matrix@1x.png` (contact matrix); per-cell 3x/4x crops are in `stills/matrix/`.

Run: `VENDOR=<dir> node matrix.js` (harness: `design/list-ordering/build/harness.js`). `check.js` covers real-tap behaviour.

- Pressed = pale tile (`--state-press`), 3px radius, on every element. On / open / selected = navy tile, paper glyph. On + pressed = `--state-on-press`. Unavailable or loading = opacity .4.
- Filled primary buttons: text/glyph flips to paper when pressed. Submit: `--figure` steps one deeper (`--figure-deep`). Floating add/account: navy steps one toward paper (`--state-on-press`); when open (inverted to `--figure`) they step one deeper (`--figure-deep`), same as submit.
- Popup pressed tiles (star, Mark Visited, Get Directions) clear the glyph/words by the same 4px on every side (`--state-tile-inset`), the star and Directions tiles share a left edge, and the close x tile is inset 3px so the popup border stays unbroken. A pressed row uses `--state-press`; a pressed FILED (visited) row uses `--state-press-filed`, one more step down, so it still reads.

**Named exceptions** (a different treatment on purpose):
1. Category chips: rule = on, dashed = off (on is the default, so it stays quiet).
2. Star / visited toggles: on = the glyph fills, no tile.
3. Floating add/account open: a navy button cannot reverse to navy, so it inverts to `--figure` with a navy glyph.
4. Sort menu: the selected order is marked by the check mark only, no fill (the fill is reserved for pressed).
5. Sort menu `is-off`: unavailable but tappable, so ink-2 text plus a reason line instead of .4.
6. Highlighted row: already reversed, so pressing it adds no deeper step.
7. Stars: the popup star's tile hugs the glyph; the add-form star's tile is the full row because its label is part of the target.

**Notes** (not exceptions): hover is pointer-only (raised paper), touch uses pressed. The row delete X has no pressed look by design (its row press is the feedback). The collapse arrow's pressed tile is 32px like the others (2px bleed; its 28px alignment box is unchanged). Rows are pressed by the `.active` class the touch handler adds; CSS `:active` is neutral on rows.

**Known polish items (not restyled):** the popup star tile's right edge sits 4px from the popup title; the right-side tiles (close x and Mark Visited) do not share a right edge.

The matrix run also fails if any crop is blank, covered, or mostly one colour.
