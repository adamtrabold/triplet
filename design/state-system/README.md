# State system

One rule per meaning, existing tokens only. The checklist below and every still are GENERATED by `matrix.js` from one table; the run asserts computed styles against the named rule and fails if any cell disagrees. To review: open `matrix@1x.png` (contact matrix); per-cell 3x/4x crops are in `stills/matrix/`.

Run: `VENDOR=<dir> node matrix.js` (harness: `design/list-ordering/build/harness.js`). `check.js` covers real-tap behaviour.

- Pressed = pale tile (`--state-press`), 3px radius, on every element. On / open / selected = navy tile, paper glyph. On + pressed = `--state-on-press`. Unavailable or loading = opacity .4.
- Filled primary buttons (submit, floating add/account): pressed steps one tone and the text/glyph flips to paper. Submit and open-floating deepen to `--figure-deep`; navy floating lightens to `--state-on-press`.
- Named exceptions: category chips (rule = on, dashed = off); star / visited toggles (on = glyph fills); floating open (a navy button cannot reverse to navy, so it inverts to `--figure`); sort menu `is-off` (unavailable but tappable, explains itself); highlighted row (already reversed, no deeper step); hover (pointer-only).
- Stars: the popup star's tile hugs the glyph (26px). The add-form star's tile is the full row on purpose: its label is part of the target, and the glyph sits 6px inside the tile.
- Collapse arrow: 32px pressed tile like the others (2px bleed; the 28px alignment box is unchanged).
